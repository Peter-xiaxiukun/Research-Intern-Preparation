# LLM Multi-Agent Summer Research Prep

This repository records my preparation for a summer research internship in LLM-based multi-agent systems.

The workspace currently contains four sections:

## 1. Daily Progress

Daily logs and progress summaries.

## 2. Knowledge Inbox

A semi-structured knowledge collection for useful concepts, tricks, open problems, evaluation issues, and research ideas.

## 3. Paper Library Index

A lightweight paper index for fast paper search using title, permanent link, and keywords.

## 4. Idea

Raw and developed research ideas.
